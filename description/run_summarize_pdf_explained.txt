58 def clean_text(text: str) -> str:
59     if not text:
60         return text
61     lines = text.replace('\r', '').split('\n')
62     kept = []
63     for line in lines:
64         s = line.strip()
65         if not s:
66             continue
67         if re.match(r'^(STORIES YOU MAY LIKE|ADVERTISEMENT)$', s, flags=re.I):
68             continue
69         if len(s) < 200 and s.isupper():
70             continue
71         if s.startswith('Video:'):
72             continue
73         kept.append(s)
74     cleaned = ' '.join(kept)
75     cleaned = re.sub(r'\s+', ' ', cleaned)
76     cleaned = re.sub(r'([!?.,]){2,}', r"\\1", cleaned)
77     return cleaned.strip()

   - `clean_text` is a utility that sanitizes raw article text before sending it to the model.
   - Line 61: normalizes Windows CR characters and splits on newlines.
   - Lines 63-73: iterate lines, strip whitespace, and drop empty/boilerplate lines:
     * Drops the markers like "STORIES YOU MAY LIKE" and "ADVERTISEMENT" (case-insensitive).
     * Drops short ALL-CAPS lines (commonly section headers) which typically don't add to summary.
     * Drops lines starting with "Video:" (UI artifacts).
   - Lines 74-76: join kept lines into a single paragraph, collapse repeated whitespace, and normalize repeated punctuation. The `re.sub` uses a backreference pattern to keep single punctuation in place of runs such as '!!!' or '...'.
   - Line 77: final strip and return.

80 def extract_text_from_pdf(path: Path) -> str:
81     try:
82         reader = PdfReader(str(path), strict=False)
83         pages = []
84         for p in reader.pages:
85             try:
86                 pages.append(p.extract_text() or "")
87             except Exception:
88                 pages.append("")
89         text = "\n".join(pages).strip()
90         return clean_text(text)
91     except PdfReadError as e:
92         print("PdfReadError while reading", path.name, ":", e)
93         return ""
94     except Exception as e:
95         print("Error reading", path.name, ":", e)
96         return ""

   - `extract_text_from_pdf` attempts to extract textual content from a PDF file.
   - Line 82: instantiates `PdfReader` with `strict=False` to be forgiving of minor PDF formatting problems. `str(path)` converts Path to a filesystem string.
   - Lines 83-88: iterate pages and call `extract_text()` (some pages may fail, those are caught and replaced with empty strings so extraction continues).
   - Line 89: join page texts with newlines and strip surrounding whitespace.
   - Line 90: returns cleaned text using the `clean_text` function.
   - Lines 91-96: if PyPDF2 raises `PdfReadError` (e.g., truncated PDF) or any other exception, print an informative message and return an empty string to signal failure.

100     prompt = f"Summarize the following text:\n{text}"

108     # Improved generation settings to reduce repetition and verbosity
109     summary_ids = model.generate(
110         inputs["input_ids"],

112         max_length=max_output_length,
113         min_length=20,
114         length_penalty=1.0,
115         num_beams=4,
116         no_repeat_ngram_size=3,

118         temperature=0.7,
119         early_stopping=True
120     )
121     summary = tokenizer.decode(summary_ids[0], skip_special_tokens=True)
122     return summary

   - Line 107: moves the input tensors to the same device as the model.

     * `num_beams`: beam search width for more coherent output.
     * `no_repeat_ngram_size=3`: prohibits repeating 3-grams to reduce repetition.
     * `repetition_penalty=1.2`: discourages token repetition.
